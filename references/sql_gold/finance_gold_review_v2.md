### F123

- **Question:** Pada tanggal berapa kenaikan harian harga penutupan TSLA terbesar (persen) selama periode dataset terjadi?
- **expected_unit:** percent
- **row_count:** 1
- **computed value:** 
- **flags:** none

```sql
WITH ordered AS (
    SELECT date, close,
           LAG(close) OVER (ORDER BY date) AS prev_close
    FROM stock_prices
    WHERE ticker = 'TSLA'
)
SELECT date, 100.0 * (close - prev_close) / prev_close AS daily_return_pct
FROM ordered
WHERE prev_close IS NOT NULL
ORDER BY daily_return_pct DESC, date ASC
LIMIT 1;
```
